# Changelog

## 1.0.0

- Initial stable release of `floating_pill_navbar`.
- Floating pill-shaped navigation container with capsule corners and soft depth shadows.
- Detached circular floating action button with press scale spring animation.
- Animated capsule indicator and color transitions between destinations.
- Support for 2, 3, 4, 5+ dynamic items with balanced width distribution.
- Optional badge counts, dot indicators, and customizable overflow limits.
- Theming support with `FloatingPillTheme` and `FloatingPillThemeData.dark()`.
- Responsive layout support for mobile, tablet, RTL, and safe insets.
- Complete example app with 10 interactive showcase screens.
